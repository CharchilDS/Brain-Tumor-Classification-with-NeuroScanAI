# NeuroScanAI - Brain Tumor Classification

A deep learning web app for brain tumor classification from MRI scans using EfficientNet.

## Features
- Classifies brain MRI scans into 4 categories: Glioma, Meningioma, Pituitary, No Tumor
- 97%+ accuracy using EfficientNet
- Grad-CAM visualization
- Built with React + FastAPI + TensorFlow
